Last updated: August 2, 2026   |   now includes app icons

UPLOAD ALL OF THESE to the repo root:
  index.html            ← the app (~487 KB). Required.
  .nojekyll             ← stops GitHub Pages running Jekyll. Required.
  favicon.ico, icon.svg, apple-touch-icon.png,
  icon-192.png, icon-512.png, icon-1024.png,
  favicon-16/32/48.png, site.webmanifest
                        ← needed for the home-screen / dock icon.

  (The other .html files are optional standalone copies of the sub-pages.)

NOTE: index.html also carries a small embedded fallback icon, so the browser
tab shows a mark even if you upload index.html alone. The HOME-SCREEN icon,
however, needs apple-touch-icon.png to be present on the server.

GITHUB WON'T OVERWRITE BY DRAG-AND-DROP
  Either open the existing file on GitHub and edit/replace its contents,
  or delete it there first, then upload.

ADD TO IPHONE HOME SCREEN
  Safari → open the site → Share → "Add to Home Screen".
  It launches full-screen (standalone) and is titled "NeuroNet".

ADD TO MAC DOCK
  Safari 17+: File → "Add to Dock".
  For a hand-made .app or a custom folder icon, use icon-macos-1024.png
  (already padded and rounded): Get Info → click the icon → paste the image.

CONFIRM THE LIVE SITE IS CURRENT
  1. Sidebar shows FOUR groups, ending in "Evidence Base → Selected Articles"
  2. Footer reads "Last updated: August 2, 2026"
  3. Hard-refresh (Cmd+Shift+R); GitHub Pages caches for a few minutes.
